# assistant-ui

Переиспользуемый web UI/PWA для alarm и будущих доменов.

## Принципы

- endpoint API задаётся конфигом, а не зашит в код;
- один UI может смотреть на домашний или облачный инстанс;
- первый вариант — server-rendered Go/HTMX, без отдельной SPA-сборки;
- аутентификация — собственная сессия сервиса, не HA-cookie;
- в HA открывается как PWA/iframe, без дублирования данных.

Страницы первого этапа: «Сегодня», будильники, таймеры, напоминания, задачи,
заметки. Позже — people/personal CRM.

Пока каталог зарезервирован; реализация появится после фиксации API.
