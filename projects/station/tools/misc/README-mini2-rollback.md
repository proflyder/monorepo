# Гайд по откату (Downgrade) прошивки Яндекс Станции Мини 2

Руководство по откату прошивки Станции Мини 2 (Amlogic A113X, `yandexmini_2`) на старую уязвимую версию для сохранения постоянного root-доступа, обхода блокировок и предотвращения окирпичивания.

---

## 1. Зачем нужен откат на старую версию

1. **Сохранение эксплоита eQuasar и root ADB**:
   В свежих версиях прошивок Яндекс отзывает старые TLS-сертификаты (eMudhra) и закрывает возможность генерации локального пароля `activate_adb.sh`.
2. **Блокировка анти-моддинг механизмов**:
   Старые версии стабильнее работают с локальными перехватчиками команд, кастомными демонами (`texted`, `lighted`, `voice_intercept`) и не перезаписывают модифицированные системные файлы.
3. **Раскирпичивание (Unbrick)**:
   Если поврежден раздел `/system` или загрузка циклит.

---

## 2. Разметка флеш-памяти (MTD / UBI)

Таблица разделов Станции Мини 2:
- `mtd0`: **bootloader** (2 MB) — первичный загрузчик
- `mtd1`: **tpl** (2 MB) — TrustZone / Secure OS
- `mtd2`: **boot** (10 MB) — Linux Kernel (zImage) + DTB + Ramdisk
- `mtd3`: **system** (80 MB) — Корневая файловая система (UBIFS `rootfs`)
- `mtd4`: **nv** (1 MB) — Заводские калибровки и серийный номер
- `mtd5`: **bkupgrade** (105 MB) — Зона OTA обновлений
- `mtd6`: **recovery** (49 MB) — Аварийный режим восстановления

---

## 3. Быстрый откат через рабочий root ADB (по сети)

Если станция сейчас доступна по сети через `adb connect 192.168.0.154:5555`:

### Шаг 1. Подготовка образов
Поместите дампы нужной старой версии в папку `./images/`:
- `images/boot.img`
- `images/system.ubi`
- `images/recovery.img`

### Шаг 2. Запуск скрипта
```bash
./rollback.sh 192.168.0.154:5555 ./images
```
Скрипт автоматически:
1. Остановит сервисы Quasar.
2. Прошьет `boot` через `nandwrite`.
3. Развернет образ `system.ubi` через `ubiformat`.
4. Заблокирует OTA-сервера Яндекса в `/etc/hosts` от повторного обновления.
5. Перезагрузит станцию в старую версию.

---

## 4. Восстановление и откат кирпича через Amlogic Burn Tool (Тестпоинт)

Если колонка не грузится по сети или застряла в bootloop:

1. **Разборка**: Снять нижнюю резиновую ножку, выкрутить винты Torx и извлечь плату.
2. **Подключение**: Подключить USB-A на USB-A (или USB Type-C) кабель к ПК.
3. **Тестпоинт (Maskrom / Boot Mode)**:
   - Замкнуть тестпоинт `EMMC_CMD` (или `CLK`) на GND пинцетом.
   - Подать питание.
   - В выводе `lsusb` на ПК появится:
     `ID 1b8e:c003 Amlogic, Inc.`
4. **Прошивка**:
   - Открыть **Amlogic USB Burning Tool**.
   - Загрузить полный образ прошивки `.img` (из дампа форума).
   - Нажать **Start**.
   - После 100% переподключить питание — станция запустится на старой прошивке с открытым портом отладки.

---

## 5. Обязательная защита от принудительного обновления после отката

Сразу после запуска старой версии добавьте в `/etc/hosts` станции:
```sh
127.0.0.1 api.quasar.yandex.net
127.0.0.1 quasar.s3.yandex.net
127.0.0.1 clck.yandex.net
```
И отключите демон обновлений:
```sh
chmod 000 /system/vendor/quasar/updatesd 2>/dev/null || true
```
Это навсегда сохранит вашу рабочую прошивку и root-доступ.
