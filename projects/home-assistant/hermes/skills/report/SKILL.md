---
name: report
description: Полный отчёт по инфраструктуре дома
---
Вызови MCP-инструмент `infra_report` сервера `infra` без аргументов. Ответь
сначала одной строкой вердикта из поля `speech`, затем приведи полный текст
отчёта из поля `details.text` как обычный текст, сохранив группировку по
узлам и пространствам имён и список алертов. Ничего не сокращай и не
переписывай своими словами. Не вызывай другие инструменты: только
`infra_report`. Если инструмент недоступен или вернул ошибку, скажи об этом
одной строкой.
