`local-history` намеренно хранит старые данные исключительно локально.
Обычный Git push передаёт достижимые объекты выбранных refs; нельзя
публиковать архивную ветку, теги на старые коммиты, mirror или весь `.git`.

## Ограничения

Сканеры не дают математической гарантии отсутствия произвольного секрета.
Hook защищает обычный push в этом checkout, но может быть обойдён вручную;
он не переносится автоматически с конфигурацией Git в новый clone.
В новом checkout включите `git config --local core.hooksPath .githooks`.

Если старые данные уже были опубликованы ранее, локальная очистка их
не отзывает: потребуется отдельно проверить удалённые refs/форки/кэши
и сменить реально скомпрометированные учётные данные.
